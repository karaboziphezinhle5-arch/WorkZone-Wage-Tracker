# WorkZone Wage Tracker

A Java-based application designed to help track worker hours, calculate wage earnings, and estimate net pay based on specified work parameters.

## Features
* **Wage Calculation:** Automatically computes total earnings based on work hours and pay rates.
* **Workzone Estimation:** Helps estimate and categorize earnings based on specific work areas and duties.
* **Clean Logic:** Built using clean, structured Java code.

* **Language:** Java
* **Tools:** Git, GitHub
